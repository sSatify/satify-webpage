SATIFY / TOOL GALLERY

SATIFY tools in action

Explore some of the innovative, time-saving tools SATIFY provides for region annotation, tracing structures and temporal analysis.

Tool gallery

01 / REGION ANNOTATION

Smart Fill

Use a prepared region mask to label matching forest patches across the image from a single selection.

02 / ROAD & RIVER TRACING

Rivers & roads pen

Draw a loose corridor around a winding road. Review the detected path and fitted width, then apply the result.

03 / MULTI-DATE ANNOTATION

Sync labelling

Label one scene and repeat the operation across other selected scenes, using each image’s own regions.

04 / INDEX DIFFERENCING

Change detection

Spot potential vegetation loss from decreases in NDVI. Adjust the threshold and label the affected areas.

05 / EXAMPLE-BASED CLASSIFICATION

Propagate labels · Experimental

Train from a few class examples, preview predictions across the image, and apply the pixels that meet your confidence threshold.
