# Short tool videos

The five approved clips are selected on `/tools/`. Their current source recordings,
exact edit versions, timing, capture commands and reproduction instructions are
maintained in [the video recipes](../../../../docs/app-videos.md).

`satellite-poses-v1.png` is a transparent two-pose adaptation of SATIFY's existing
satellite, produced with the built-in image generator. The adjacent JSON retains
the reference and full prompt. Left: curious; right: delighted. The mascot stays
large and fixed throughout the clips, sometimes crossfading to the happy pose.

All selected exports are silent, landscape, 1280 × 720 at 30 fps. The five
`edit-*-micro.py` editors, their local previews, the reusable recorder and exact
approved sources remain under `tools/videos/`. New outputs go to ignored
`output/`; final assets alone go into `web/assets/videos/gallery/`.
