# Approved recording sources

These five recordings are editing inputs for the current short Tool Gallery
videos. They are versioned separately from `web/` and never copied to the site.

- Three MP4s and `recordings.json` preserve the selected longer Smart Fill,
  Sync labelling and Propagate captures and their original checksums/provenance.
- Two WebMs and their JSON manifests preserve the local revision-2 road capture
  and the NDVI/histogram capture. Paths are relative to each manifest; raw hashes
  are pinned. Manifests omit private browser state and project identifiers.

See [the complete current video recipes](../../../../docs/app-videos.md) for
commands, timing and verification. These are sources, not additional gallery clips.
